The `@repo/email` package provides a complete transactional email system with React Email templates and support for multiple email providers.

## Features

- **Dual Provider Support**: Switch between Resend (production) and Nodemailer (local development)
- **React Email Templates**: 21 pre-built templates for common use cases
- **i18n Support**: Message catalogs for English and Spanish (the `Locale` type declares more locales for future use, but only `en`/`es` have translated content)
- **Type-Safe**: Full TypeScript support with validated configurations
- **Auto-Detection**: Automatically selects the appropriate provider based on environment

## Architecture

```
packages/email/
├── providers/           # Email provider implementations
│   ├── types.ts         # Interface definitions
│   ├── resend.ts        # Resend provider
│   ├── nodemailer.ts    # Nodemailer provider
│   └── index.ts         # Provider factory
├── templates/           # React Email templates
├── components/          # Shared UI components
├── i18n/                # Translation messages
├── config.ts            # Environment configuration
└── index.ts             # Public API
```

## Quick Start

### Installation

The package is already included in the monorepo. Import it in your app:

```typescript
import { sendWelcomeEmail, sendPasswordResetEmail } from '@repo/email';
```

### Send an Email

```typescript
await sendWelcomeEmail({
  email: 'user@example.com',
  name: 'John Doe',
});
```

## Template Categories

| Category | Templates |
|----------|-----------|
| **Auth & Security** | Password Reset, Email Verification, Magic Link, Sign-In OTP, Verification OTP, 2FA OTP, Account Locked, Password Changed, Login from New Device |
| **Organization** | Invitation, Invitation Accepted, Role Changed, Removed from Org |
| **Billing** | Subscription Started, Upgraded, Downgraded, Cancelled, Payment Receipt |
| **Content** | Article Published, Welcome, Account Deleted |

<Callout type="info">
Not every template is currently wired up to a real code path — see [Templates](/docs/email/templates) for which ones the app actually triggers today versus which exist but aren't called from anywhere yet.
</Callout>
