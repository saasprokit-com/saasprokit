## Provider Architecture

The email package uses a provider abstraction pattern that allows switching between different email services without changing application code.

```typescript
interface EmailProvider {
  name: string;
  send(options: SendEmailOptions): Promise<SendEmailResult>;
}

interface SendEmailOptions {
  to: string | string[];
  subject: string;
  react: React.ReactElement;
  from?: string;
  replyTo?: string;
  cc?: string[];
  bcc?: string[];
}

interface SendEmailResult {
  success: boolean;
  messageId?: string;
  error?: Error;
}
```

## Resend Provider

[Resend](https://resend.com) is a modern email API designed for developers. It's the recommended provider for production environments.

### Features

- Native React Email support (no HTML conversion needed)
- High deliverability rates
- Real-time analytics and logs
- Webhook support for tracking events
- Domain verification for branded sending

### Configuration

```bash
EMAIL_PROVIDER=resend
RESEND_API_KEY=re_xxxxxxxxxxxxx
EMAIL_FROM="Your App <noreply@yourdomain.com>"
```

### Implementation

```typescript
// providers/resend.ts
import { Resend } from 'resend';
import type { EmailProvider, SendEmailOptions, SendEmailResult } from './types';

export class ResendProvider implements EmailProvider {
  name = 'resend' as const;
  private client: Resend;

  constructor(apiKey: string) {
    this.client = new Resend(apiKey);
  }

  async send(options: SendEmailOptions): Promise<SendEmailResult> {
    const { data, error } = await this.client.emails.send({
      from: options.from!,
      to: options.to,
      subject: options.subject,
      react: options.react, // Native React support
      replyTo: options.replyTo,
      cc: options.cc,
      bcc: options.bcc,
    });

    if (error) {
      return { success: false, error: new Error(error.message) };
    }

    return { success: true, messageId: data?.id };
  }
}
```

### Domain Setup

1. Add your domain in Resend Dashboard
2. Add the required DNS records (SPF, DKIM, DMARC)
3. Wait for verification (usually a few minutes)
4. Update `EMAIL_FROM` to use your verified domain

<Callout type="warn">
  Using an unverified domain will result in emails being sent from `onboarding@resend.dev` instead of your domain.
</Callout>

## Nodemailer Provider

[Nodemailer](https://nodemailer.com) is a Node.js module for sending emails via SMTP. It's ideal for local development and self-hosted SMTP servers.

### Features

- Works with any SMTP server
- No external API dependencies
- Perfect for local development with Maildev
- Connection pooling for high-volume sending

### Configuration

```bash
EMAIL_PROVIDER=nodemailer
SMTP_HOST=localhost
SMTP_PORT=1025
SMTP_SECURE=false
SMTP_USER=           # Optional
SMTP_PASS=           # Optional
SMTP_POOL=false      # Optional — connection pooling
```

### Implementation

```typescript
// providers/nodemailer.ts
import nodemailer from 'nodemailer';
import type { Transporter } from 'nodemailer';
import { render } from '@react-email/render';
import type { EmailProvider, SendEmailOptions, SendEmailResult } from './types';

export class NodemailerProvider implements EmailProvider {
  name = 'nodemailer' as const;
  private transporter: Transporter;

  constructor(config: SMTPConfig) {
    this.transporter = nodemailer.createTransport({
      host: config.host,
      port: config.port,
      secure: config.secure,
      auth: config.user ? { user: config.user, pass: config.pass } : undefined,
      pool: config.pool,
    });
  }

  async send(options: SendEmailOptions): Promise<SendEmailResult> {
    // Convert React Email component to HTML
    const html = await render(options.react);
    const text = await render(options.react, { plainText: true });

    const info = await this.transporter.sendMail({
      from: options.from,
      to: Array.isArray(options.to) ? options.to.join(', ') : options.to,
      subject: options.subject,
      html,
      text,
      replyTo: options.replyTo,
      cc: options.cc,
      bcc: options.bcc,
    });

    return { success: true, messageId: info.messageId };
  }
}
```

## Provider Comparison

| Feature | Resend | Nodemailer |
|---------|--------|------------|
| **Best For** | Production | Local Development |
| **React Support** | Native | Via `@react-email/render` |
| **Setup Complexity** | Low (API key only) | Medium (SMTP config) |
| **Cost** | Free tier available | Free (self-hosted) |
| **Deliverability** | High | Depends on SMTP server |
| **Analytics** | Built-in dashboard | Manual tracking |
| **Offline Support** | No | Yes (with local SMTP) |

## Provider Factory

The provider is selected and instantiated automatically:

```typescript
// providers/index.ts
import { keys } from '../keys';
import { ResendProvider } from './resend';
import { NodemailerProvider } from './nodemailer';

const env = keys();
let cachedProvider: EmailProvider | null = null;

export function getEmailProvider(): EmailProvider {
  if (cachedProvider) return cachedProvider;

  const providerType = env.EMAIL_PROVIDER || detectProvider();

  if (providerType === 'resend') {
    if (!env.RESEND_API_KEY) {
      throw new Error('RESEND_API_KEY required for Resend provider');
    }
    cachedProvider = new ResendProvider(env.RESEND_API_KEY);
  } else {
    cachedProvider = new NodemailerProvider({
      host: env.SMTP_HOST,
      port: env.SMTP_PORT,
      secure: env.SMTP_SECURE,
      user: env.SMTP_USER,
      pass: env.SMTP_PASS,
      pool: env.SMTP_POOL,
    });
  }

  return cachedProvider;
}
```

## Adding Custom Providers

To add a new provider (e.g., SendGrid, Mailgun):

1. Create a new file in `providers/`
2. Implement the `EmailProvider` interface
3. Add configuration to `keys.ts`
4. Update the factory in `providers/index.ts`

```typescript
// providers/sendgrid.ts
import sgMail from '@sendgrid/mail';
import { render } from '@react-email/render';
import type { EmailProvider, SendEmailOptions, SendEmailResult } from './types';

export class SendGridProvider implements EmailProvider {
  name = 'sendgrid' as const;

  constructor(apiKey: string) {
    sgMail.setApiKey(apiKey);
  }

  async send(options: SendEmailOptions): Promise<SendEmailResult> {
    const html = await render(options.react);

    await sgMail.send({
      to: options.to,
      from: options.from!,
      subject: options.subject,
      html,
    });

    return { success: true };
  }
}
```
