## System Requirements

### Minimum Requirements

- **Node.js**: 18.0.0 or higher (recommended 20+ LTS)
- **pnpm**: 8+ (required, project uses pnpm workspaces)
- **Git**: 2.0 or higher
- **Operating System**: macOS, Linux, or Windows (WSL2 recommended for Windows)

### Recommended Setup

- **Node.js**: 20.11+ (LTS)
- **pnpm**: 9.0+
- **RAM**: 8GB minimum (16GB recommended for smooth development)
- **Disk Space**: 5GB+ for dependencies and build artifacts
- **Terminal**: zsh or bash on Unix-like systems

## External Services

### Required for Production

1. **Database**
   - PostgreSQL 12+ instance
   - Recommended: Neon (serverless PostgreSQL)
   - Alternative: Self-hosted or AWS RDS

2. **Authentication**
   - Better Auth configured with PostgreSQL adapter
   - OAuth applications (Google, GitHub) — optional but recommended

3. **Email Service**
   - Resend (recommended) for transactional emails
   - Used for sign-up confirmations, password resets, invitations

4. **Payment Processing**
   - Stripe account (test or live)
   - For subscription billing and payment handling

### Optional

- **File Storage**: AWS S3 or compatible (Cloudflare R2) for cloud uploads
- **Monitoring**: Sentry for error tracking
- **Logging**: Pino configured out of the box

## Development Environment Setup

### macOS with Homebrew

```bash
# Install Node.js LTS
brew install node@20

# Install pnpm
npm install -g pnpm@latest

# Install Git (usually pre-installed)
brew install git
```

### Ubuntu/Debian

```bash
# Install Node.js LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install pnpm
npm install -g pnpm@latest

# Install Git
sudo apt-get install -y git
```

### Windows (WSL2)

```bash
# Install Node.js LTS via WSL
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install pnpm
npm install -g pnpm@latest

# Install Git
sudo apt-get install -y git
```

## Database Setup

### Local PostgreSQL

```bash
# Install PostgreSQL
brew install postgresql@15  # macOS

# Start PostgreSQL
brew services start postgresql@15

# Create database
createdb saasprokit_dev

# Set DATABASE_URL
export DATABASE_URL="postgresql://localhost/saasprokit_dev"
```

### Neon (Recommended for Development)

1. Create account at [neon.tech](https://neon.tech)
2. Create a new project
3. Copy the connection string to `.env.local`
4. Run: `pnpm migrate`

## Verification

To verify your setup is correct:

```bash
# Check Node version
node --version  # Should be 18.0.0 or higher

# Check pnpm version
pnpm --version  # Should be 8.0.0 or higher

# Check Git version
git --version  # Should be 2.0 or higher

# Test project setup
pnpm install
pnpm build
```

If all commands succeed without errors, your environment is ready for development.
