## Running Unit Tests

```bash
# Run all unit tests
pnpm test

# Run auth package tests only
pnpm --filter auth test

# Run in watch mode
pnpm --filter auth test -- --watch

# Run a specific test by name
pnpm --filter auth test -- --grep "ORG_ROLES"
```
