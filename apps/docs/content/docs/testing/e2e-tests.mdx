## Running these tests

```bash
pnpm --filter app test:e2e                          # all E2E tests
pnpm --filter app test:e2e -- --grep "Sign In"       # by describe/test title
pnpm --filter app test:e2e -- e2e/payment            # by folder
pnpm --filter app test:e2e:ui                        # with the Playwright UI
```
