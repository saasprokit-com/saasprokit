## Running Tests

### E2E Tests (Playwright)

```bash
# Run all E2E tests
pnpm --filter web test:e2e

# Run with browser UI
pnpm --filter web test:e2e:ui

# Run a specific test file
pnpm --filter web test:e2e -- --grep "Sign In"

# Run a specific test by ID
pnpm --filter web test:e2e -- --grep "TC-05-05"
```

### Unit Tests (Vitest)

```bash
# Run all unit tests
pnpm test

# Run tests for a specific package
pnpm --filter auth test
pnpm --filter web test

# Run in watch mode
pnpm --filter auth test -- --watch
```

## Test File Organization

### E2E Tests

E2E tests are organized in two structures:

**Numbered flow tests** (`apps/web/e2e/01-*.spec.ts` through `24-*.spec.ts`):
Sequential page-by-page tests covering every screen in the app. Each file covers one page with both UI display tests and functional tests.

**Categorized domain tests** (`apps/web/e2e/auth/`, `apps/web/e2e/payment/`):
Focused domain-specific tests that group related functionality. These overlap with the numbered tests but use a different naming convention (e.g. `SI-01` vs `TC-02-01`).

### Unit Tests

Unit tests are co-located with source files in `packages/`:
```
packages/auth/permissions.test.ts
```
