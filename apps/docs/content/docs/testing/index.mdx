## Running Tests

### E2E Tests (Playwright)

```bash
# Run all E2E tests
pnpm --filter app test:e2e

# Run with browser UI
pnpm --filter app test:e2e:ui

# Run a specific test file
pnpm --filter app test:e2e -- --grep "Sign In"

# Run a specific folder
pnpm --filter app test:e2e -- e2e/payment
```

### Unit Tests (Vitest)

```bash
# Run all unit tests
pnpm test

# Run tests for a specific package
pnpm --filter auth test
pnpm --filter app test

# Run in watch mode
pnpm --filter auth test -- --watch
```

## Test File Organization

### E2E Tests

E2E specs live in domain folders under `apps/web/e2e/`: `account/`, `auth/`, `dashboard/`, `members/`, `payment/`, `public/`, plus `fixtures/`, `helpers/`, and `setup/` for shared test infrastructure (e.g. the Maildev REST helper — see [Local Development](/docs/email/local-development)). See [E2E Tests](/docs/testing/e2e-tests) for the full file list.

### Unit Tests

Unit tests are co-located with their source files:
```
packages/auth/permissions.test.ts
packages/auth/billing-authorize.test.ts
packages/payment/helpers.test.ts
apps/web/lib/routes.test.ts
apps/web/lib/parsers.test.ts
apps/web/app/[locale]/(app)/[orgSlug]/checkout/success/verify-session.test.ts
```
