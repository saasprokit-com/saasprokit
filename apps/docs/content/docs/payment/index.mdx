The project uses **Stripe** for all payment processing, integrated through the **Better Auth Stripe plugin** and a custom webhook layer. Billing is scoped to organizations — each organization has its own subscription.

## Architecture

```
packages/
├── payment/              # Plan definitions, guards, helpers, hooks
├── utils/payment.ts      # Constants, pricing, Stripe price mapping
└── auth/server.ts        # Better Auth Stripe plugin config

apps/web/
├── lib/billing/
│   ├── stripe.ts                 # Stripe client singleton
│   ├── webhook-handlers.ts       # Event handlers (emails, validation)
│   └── subscription-queries.ts   # Database queries for subscriptions/usage
├── app/api/stripe/webhook/       # Webhook POST endpoint
└── app/[locale]/(app)/[orgSlug]/billing/
    ├── page.tsx         # Billing dashboard
    ├── actions.ts       # Server actions (checkout, portal, plan change)
    ├── schemas.ts       # Zod validation
    └── components/      # UI components
```

## Key Concepts

### Organization-Scoped Billing

Every subscription is tied to an organization via `referenceId`. Users don't have individual subscriptions — they manage billing through their organization.

### Dual Integration

1. **Better Auth Stripe Plugin** — Handles subscription sync to the database, customer creation, and plan authorization
2. **Custom Webhook Handlers** — Send transactional emails and handle business logic beyond what the plugin provides

### Three-Tier Subscription Model

| Plan | Monthly | Annual | Members | Storage |
|------|---------|--------|---------|---------|
| Free | $0 | $0 | 1 | 100 MB |
| Pro | $19 | $190 | 10 | 5 GB |
| Enterprise | $49 | $490 | 50 | 50 GB |

## Data Models

### Subscription

```prisma
model Subscription {
  id                   String    @id @default(cuid())
  plan                 String    // "free", "pro", "enterprise"
  referenceId          String    // organizationId
  stripeCustomerId     String?
  stripeSubscriptionId String?
  status               String?   @default("incomplete")
  periodStart          DateTime?
  periodEnd            DateTime?
  cancelAtPeriodEnd    Boolean?  @default(false)
  seats                Int?
}
```

### WebhookEvent

Used for idempotent webhook processing — prevents duplicate email sends and state updates.

```prisma
model WebhookEvent {
  id          String    @id @default(cuid())
  provider    String    // "stripe"
  eventId     String    // Stripe event ID
  eventType   String    // "invoice.paid", etc.
  data        String    // Full event JSON
  status      String    @default("pending")
  attempts    Int       @default(0)

  @@unique([provider, eventId])
}
```
