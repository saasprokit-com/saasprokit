## Plan Tiers

The project ships with three subscription plans defined in `packages/payment/plans.ts`:

| Plan | Monthly | Annual | Savings | Badge |
|------|---------|--------|---------|-------|
| **Free** | $0 | $0 | — | — |
| **Pro** | $19 | $190/yr | ~17% | Most Popular |
| **Enterprise** | $49 | $490/yr | ~17% | — |

### Plan Limits

| Resource | Free | Pro | Enterprise |
|----------|------|-----|------------|
| Team Members | 1 | 10 | 50 |
| Storage | 100 MB | 5 GB | 50 GB |
| Priority Support | No | Yes | Yes |
| Advanced Analytics | No | Yes | Yes |

Constants are defined in `packages/utils/payment.ts`:

```typescript
import { PRICING, LIMITS, PLAN_NAMES } from "@repo/utils/payment";

LIMITS.FREE.MAX_MEMBERS    // 1
LIMITS.PRO.MAX_STORAGE_MB  // 5000
PRICING.PRO.MONTHLY        // 19
PRICING.PRO.YEARLY         // 190
```

## Plan Configuration

Each plan is a `PlanConfig` object:

```typescript
type PlanConfig = {
  name: PlanName;          // "free" | "pro" | "enterprise"
  displayName: string;
  description: string;
  monthlyPrice: number;
  yearlyPrice: number;
  limits: {
    maxMembers: number;
    maxStorageMB: number;
    prioritySupport: boolean;
    advancedAnalytics: boolean;
  };
  features: string[];       // Display strings for pricing cards
  highlighted?: boolean;    // Highlight on pricing page
  badge?: string;           // e.g. "Most Popular"
};
```

### Utility Functions

```typescript
import {
  getPlanConfig,
  getAllPlans,
  isPlanHigherTier,
  comparePlans,
  getAnnualSavingsPercent,
} from "@repo/payment/plans";

// Get a specific plan
const pro = getPlanConfig("pro");

// Compare plans
comparePlans("free", "pro");       // "upgrade"
comparePlans("enterprise", "pro"); // "downgrade"
comparePlans("pro", "pro");        // "same"

// Check tier ordering
isPlanHigherTier("pro", "free");   // true
```

## Stripe Price Mapping

Stripe price IDs are mapped from environment variables:

```typescript
import { getStripePriceMap } from "@repo/utils/payment";

const priceMap = getStripePriceMap({
  proMonthly: env.STRIPE_PRO_PRICE_ID_MONTHLY,
  proAnnual: env.STRIPE_PRO_PRICE_ID_ANNUAL,
  enterpriseMonthly: env.STRIPE_ENTERPRISE_PRICE_ID_MONTHLY,
  enterpriseAnnual: env.STRIPE_ENTERPRISE_PRICE_ID_ANNUAL,
});

// Result:
// { pro_monthly: "price_xxx", pro_yearly: "price_xxx", ... }
```

The `getPlanNameFromPriceId()` function reverses this mapping — used by webhooks and the auth plugin to determine which plan a Stripe price corresponds to.

## Organization Creation Rules

Organization creation is gated by subscription status:

1. **Every user gets 1 free organization** — no payment required
2. **Additional orgs require all existing orgs to have paid plans** — only 1 free org allowed
3. **Hard cap of 10 organizations per user** (configurable via `MAX_ORGS_PER_USER`)

```typescript
import { checkOrgCreationEligibility } from "@repo/utils/payment";

const result = checkOrgCreationEligibility(
  ownedOrgCount,   // How many orgs the user owns
  freePlanCount,   // How many of those are on free plans
  maxOrgsPerUser   // Hard cap (default 10)
);

// result.eligible: boolean
// result.reason?: string (if not eligible)
```

```typescript
SUBSCRIPTION_STATUS.PAUSED             // "paused"
SUBSCRIPTION_STATUS.INCOMPLETE         // "incomplete"
SUBSCRIPTION_STATUS.INCOMPLETE_EXPIRED // "incomplete_expired"
SUBSCRIPTION_STATUS.UNPAID             // "unpaid"
```

Active statuses (subscription considered valid): `active`, `past_due`, `incomplete`.

## Downgrade Guards

Before downgrading, the system validates that the organization's current usage fits within the target plan's limits:

```typescript
import { guardDowngrade } from "@repo/payment/guards";

const result = guardDowngrade({
  currentMembers: 8,
  currentStorageMB: 3000,
  targetPlan: "free",  // free only allows 1 member, 100 MB
});

// result.blocked: true
// result.reason: "Current members (8) exceed free plan limit (1)"
```

This prevents data loss — users must reduce their usage before downgrading.
