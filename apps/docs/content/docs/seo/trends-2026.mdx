## INP (Interaction to Next Paint)

### Overview

INP replaced FID as a Core Web Vital in March 2024.

| Metric | Target | Status |
|--------|--------|--------|
| Good | ≤200ms | Green |
| Needs Improvement | 200-500ms | Yellow |
| Poor | >500ms | Red |

### Optimization Checklist

| Status | Task | Priority |
|--------|------|----------|
| [ ] | Use React 18 Transitions | Critical |
| [ ] | Debounce/throttle handlers | High |
| [ ] | Use passive event listeners | Medium |
| [ ] | Implement code splitting | High |
| [ ] | Defer non-critical JS | High |
| [ ] | Use Web Workers | Medium |
| [ ] | JS budget ≤150KB | Medium |

```typescript
import { useTransition } from 'react'

function SearchBox() {
  const [isPending, startTransition] = useTransition()
  const [query, setQuery] = useState('')

  const handleChange = (e) => {
    // Mark heavy operations as non-urgent
    startTransition(() => {
      setQuery(e.target.value)
      performExpensiveSearch(e.target.value)
    })
  }

  return (
    <div>
      <input onChange={handleChange} />
      {isPending && <span>Searching...</span>}
    </div>
  )
}
```
